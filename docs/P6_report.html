P6 · Flavonoid bioactivity curation and QSAR: xanthine oxidase (ChEMBL)

R&D / lab data · ChEMBL REST API (human + bovine XO) · Python, RDKit, scikit-learn · continues BPharm flavonoid thesis
Curated 4,443 ChEMBL records into 1,786 clean compounds (170 flavonoids). Known flavonoid SAR reappears in the data, and a scaffold-split model reaches R2 0.73 against 0.83 on an optimistic random split.

Question

Can public bioactivity data on xanthine oxidase be curated into a trustworthy dataset, and does it reproduce what bench chemists know about flavonoid structure-activity?

Data

  • ChEMBL activities for CHEMBL1929 (human) and CHEMBL3649 (bovine milk XO)
  • IC50 in nM with exact relation; SMILES per molecule
  • Curated output: one row per InChIKey with median pIC50, SD, species, class, SAR flags

Method

  • 10-step documented curation funnel (validity, duplicates, units, range)
  • RDKit standardisation: largest fragment, uncharge, cleanup; InChIKey dedup
  • Flavonoid classes and SAR flags via unit-tested SMARTS
  • Morgan fingerprints plus descriptors, random forest and gradient boosting
  • Scaffold split vs random split; bootstrap CIs; mean baseline

Limitations

  • Human and bovine XO pooled; assay conditions differ by lab
  • Censored '>' values dropped, so the dataset is biased towards actives
  • Univariate SAR on small n; no matched molecular pairs
  • No applicability-domain filter yet

Next steps

  • Add censored inactives as a classification task
  • Matched-molecular-pair analysis on flavone OH patterns
  • Score the Elsholtzia ciliata flavonoids from the thesis with the model
  • Use for data-curator applications (A*STAR, EDDC, AI drug-discovery teams)
